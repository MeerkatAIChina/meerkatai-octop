## 遗留与注意

- `Sidebar.tsx` / `Header.tsx` 中对 `CurrentVersionBadge` 的既存注释属另一件事，不在本次 10 项清单内
- tab key 全局唯一是 §3.4 的前提。本次新增了 `oidc` / `ldap` / `updates` 三个 key 到隐藏集，将来若其它页面出现同名 tab 会被误伤
- **后端 `SIDEBAR_NAV_KEYS`（`src/octop/infra/users/preferences.py:22-44`）不得改动**。改动会使 `validate_sidebar_nav()` 抛错 → `get_sidebar_nav_from_json()` 返回 `None` → 用户的**整个**导航布局被静默丢弃，而非仅丢失这几项
- 恢复方式：从 `hiddenFeatures.ts` 移除对应 key，并撤销 Task 7 的注释
