## Task 5 — 行尾符治理（配套）

- [x] `git config core.autocrlf input`（仅本仓库）

理由：仓库索引存储 LF，而全局 `autocrlf=true` 使 checkout 产出 CRLF、prettier 又写回 LF，两者反复冲突。`input` 在提交时做 CRLF→LF 归一化、checkout 不做转换，使差异只反映真实改动。
