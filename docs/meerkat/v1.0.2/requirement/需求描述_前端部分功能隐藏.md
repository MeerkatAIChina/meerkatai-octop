# 前端部分功能隐藏

## 需求描述

前端暂时隐藏部分功能，不对用户开放，需要隐藏的入口包括：导航栏内的菜单、某些页面上的 tab 或按钮。

### 目前隐藏功能如下

| 功能       | 入口           | 性质     |
| ---------- | -------------- | -------- |
| 云端协同   | 导航栏 → 设置  | 整个页面 |
| 工作台     | 导航栏 → 控制  | 整个页面 |
| 远程桌面   | 导航栏 → 控制  | 整个页面 |
| ACP        | 导航栏 → 控制  | 整个页面 |
| 通用 OIDC  | 用户管理页     | 功能     |
| LDAP       | 用户管理页     | 功能     |
| 应用更新   | 应用设置页     | 功能     |
| 帮助与反馈 | 左下角用户菜单 | 跳转链接 |
| 项目地址   | 左下角用户菜单 | 跳转链接 |
| 检查更新   | 左下角用户菜单 | 功能     |
