# 前端主题色修改 — 技术规格

## 1. 目标

将项目默认品牌色由 `rose`（`#E85D75`）改为内置预设 `tech`（`#3A5FE0`），并消除首屏品牌色闪烁。

## 2. 设计总则

复用内置 `tech` 预设，**不做颜色推导、不新增调色板、不修改 `theme-vars.css`**。改动集中在「默认值」与「首屏时序」两处。

## 3. 改动设计

### 3.1 切换默认调色板

`styles/themePalettes.ts:28`

```diff
-export const DEFAULT_PALETTE: ThemePalette = "rose";
+export const DEFAULT_PALETTE: ThemePalette = "tech";
```

作用：无存储值者（新用户 / 清除过 localStorage）默认得到 tech。

### 3.2 boot 脚本补设 `data-palette`

`index.html:39-115`。在既有明暗解析之外，新增品牌色解析并在首次绘制前写入 `<html>`。

**接口契约** —— 解析优先级必须与 `appearanceStorage.ts:45-87` 的 `readStoredAppearance()` **完全一致**，否则 React 挂载后可能算出不同结果：

| 优先级 | 来源 | 校验 |
|---|---|---|
| 1 | `localStorage["theme"]` JSON 的 `palette` 字段 | 必须在合法值集合内 |
| 2 | `localStorage["octop:ui-palette"]`（legacy 键） | 同上 |
| 3 | `DEFAULT_PALETTE` | — |

合法值集合 = `VALID_PALETTES`（8 套预设）+ `"custom"`。

脚本先于任何 bundle 执行、无法 import TS 模块，因此**在 `index.html` 内自带一份合法值列表与默认值的副本**，需与 `themePalettes.ts` 手工同步（由测试守卫，见 §5）。

输出：

```js
document.documentElement.setAttribute("data-theme", mode);
document.documentElement.setAttribute("data-palette", palette);
```

### 3.3 动画环跟随品牌色

`index.html:166-181`。硬编码色值改为 CSS 变量 + tech 兜底：

| 位置 | 值 |
|---|---|
| 浅色描边 | `rgba(58, 95, 224, 0.18)` |
| 浅色环顶 | `var(--fn-color-brand, #3a5fe0)` |
| 暗色描边 | `rgba(123, 155, 252, 0.22)` |
| 暗色环顶 | `var(--fn-text-brand, #7b9bfc)` |

设计说明：

- **用变量而非新硬编码**：theme-vars.css 加载后动画环跟随当前调色板，而非固定 tech
- **保留兜底值**：CSS 加载前的首次绘制用 tech 值，不会出现无色
- **暗色取 `--fn-text-brand`**：沿用 rose 原设计的可读性处理（暗色下主色过深，需用提亮变体）

## 4. 不改动的部分

| 对象 | 原因 |
|---|---|
| `theme-vars.css` | boot 脚本总是设置 `data-palette` 后，`html[data-palette="tech"]`（特异性 0,2,1）恒压过 `:root`（0,1,0） |
| 153 个 `.less` 文件 | 无全局 less 变量，颜色一律走 `var(--fn-*)` |
| ~15 处硬编码 `#1677ff` | 不随主题变化，本次保留 |

## 5. 测试设计

`styles/bootTheme.test.ts` 新增 `describe("index.html boot palette")`，8 个用例覆盖：无存储取默认值、遍历全部合法预设、`custom`、非法值回落、JSON 缺 `palette` 字段、legacy 键迁移、JSON 优先于 legacy、legacy 值非法。

其中两条兼作**副本防脱钩守卫**：

- 「无存储时等于 `DEFAULT_PALETTE`」
- 「遍历 `VALID_PALETTES` 全部通过」

boot 脚本自带的副本一旦与 `themePalettes.ts` 不一致，这两条即失败。

`utils/expertColor.test.ts` 中 2 条断言由字面量 `"rose"` 改为引用 `DEFAULT_PALETTE`，使其跟踪真实契约（兜底到默认调色板）而非固定色值。

## 6. 验收标准

1. 清空 localStorage 后打开页面，首屏即为 tech 蓝，无 rose 闪烁
2. `data-palette` 在首次绘制前已由 boot 脚本设置
3. `bootTheme.test.ts` 全绿；`tsc -b`、`eslint` 通过
