# 前端主题色修改 — 需求调研

> 调研对象：`dashboard/` 前端主题色体系。所有结论标注文件与行号。

## 1. 主题系统架构

主题由两个正交维度驱动，通过 `<html>` 上的属性控制：

| 维度 | 属性 | 取值 |
|---|---|---|
| 明暗 | `data-theme` | `light` / `dark` |
| 品牌色 | `data-palette` | 8 套预设 + `custom` |

同一份品牌色要同时喂给两个层次，**且两者是手工维护的双份数据**：

| 层 | 文件 | 作用对象 |
|---|---|---|
| antd Token | `styles/themePalettes.ts:73-245` | antd 组件（按钮 / 开关 / 链接） |
| CSS 变量 | `styles/theme-vars.css` | 自定义样式（侧边栏 / 选中态 / 气泡） |

## 2. 调色板定义

- 预设清单：`themePalettes.ts:14-23`，共 8 套 —— `rose tech indigo teal violet emerald amber slate`
- 色标：`themePalettes.ts:46-56` `PALETTE_SWATCH`
- antd token：`themePalettes.ts:73-245` `ANTD_BRAND_TOKENS`，按 `调色板 × 明暗` 组织
- 另有运行时可推导的 `custom`（`themePalettes.ts:351-379` `customBrandTokens()`），由用户所选 hex 生成全套 token

**`tech` 预设**（本次选定的品牌色）主色 `#3A5FE0`，暗色文字变体 `#7B9BFC`；CSS 变量块见 `theme-vars.css:377-445`。

## 3. 运行时链路

```
localStorage["theme"] { preference, palette, customColor }
   ↓
ThemeContext.tsx            → 写 <html data-palette> / <html data-theme>
   ↓
App.tsx:45-49               → brandTokensFor(palette, isDark, customColor)
   ↓
<ConfigProvider theme>      → antd 组件
```

存储读写：`styles/appearanceStorage.ts:45-87` `readStoredAppearance()`，解析优先级为
`JSON.palette` → legacy 键 `octop:ui-palette` → `DEFAULT_PALETTE`。

## 4. 首屏渲染边界（本次要解决的核心问题）

`index.html` 的 `<head>` 内有一段内联 boot 脚本（`index.html:39-115`），在任何 bundle 之前执行，用于消除明暗闪烁。

**但它只设置 `data-theme`，不设置 `data-palette`。** 后果：

- React 挂载前，`:root` 基础块（`theme-vars.css:9-369`，即 rose 的定义）生效 → 切换默认品牌色后首屏闪一次旧色
- 加载动画环 `index.html:166-181` 同样是硬编码的 rose（`#e85d75` / `#f08b9a`），不受 `data-palette` 影响

## 5. 改造成本边界

- **`theme-vars.css` 无需改动**。boot 脚本一旦总是设置 `data-palette`，`html[data-palette="tech"]`（特异性 0,2,1）恒压过 `:root`（0,1,0）。`:root` 的角色是「rose 预设的定义」，这正是 rose 没有独立覆盖块的原因。
- **全部 153 个 `.less` 文件无需改动**。项目无全局 less 变量（`vite.config.ts:282-286` 仅设 `javascriptEnabled`），颜色一律引用 `var(--fn-*)`。
- **副作用需知悉**：`DEFAULT_PALETTE` 同时是专家 / 子代理头像的兜底色（`utils/expertColor.ts:42,50,52`），改动会连带影响这些头像的默认颜色。
- **不在本次范围**：约 15 处未带 `var()` 的硬编码 `#1677ff`（如 `pages/Chat/components/TrajectoryToolbar.module.less:106,122`），它们不随主题变化，本次保留。

## 6. 结论

选定的品牌色 `tech` **已是内置预设**，无需新增调色板、无需做颜色推导，直接复用现有色值即可。改动收敛为 3 个文件：`themePalettes.ts`、`index.html`（两处）、`bootTheme.test.ts`。
